# JARVIS Python Assistant

A beginner-friendly AI assistant project built in Python.

## Features
- Greets the user
- Tells the time
- Opens Google, YouTube, and GitHub
- Remembers name and city
- Stores custom facts
- Searches Google and YouTube

## Project Structure
```text
jarvispython/
│
├── main.py
├── memory.json
├── requirements.txt
├── README.md
│
└── jarvis/
    ├── __init__.py
    ├── actions.py
    ├── memory.py
    └── router.py
```

## How to Run
Open terminal in the project folder and run:

```bash
python main.py
```

## Example Commands
- hello
- time
- open github
- remember my name
- what is my name
- remember that my favorite food is pizza
- what is my favorite food
- search google for python dictionaries
